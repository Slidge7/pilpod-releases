# PilPod Releases

Official download location for **PilPod Desktop**, the media command center for Windows.

- Website: https://pilpod.ma
- Browser extension: [PilPod Companion on the Chrome Web Store](https://chromewebstore.google.com/detail/pilpod-companion/ooogjmdnagfepkocppnldkafbcbmdhal)

## Download

Get the latest installer from the [Releases](https://github.com/Slidge7/pilpod-releases/releases) page.

| Requirement | |
|---|---|
| OS | Windows 10 / 11, 64-bit |
| Installer | `PilPod_Setup_<version>_x64.exe` |

Each release lists the installer's SHA-256 so you can verify the download:

```powershell
Get-FileHash .\PilPod_Setup_2.0.0_x64.exe -Algorithm SHA256
```

## Privacy

PilPod runs entirely on your computer: no account, no telemetry, no servers.
See the [PilPod Desktop privacy policy](https://pilpod.ma/privacy/desktop).

This repository only hosts release binaries; it contains no source code.
